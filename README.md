Sahil Naseem --- Data & Analytics Portfolio

A personal portfolio website showcasing Sahil Naseem's work, projects,
education, technical skills, and professional interests across Data
Analytics, Business Analytics, and Data Science.

Overview

This portfolio is designed as a visual presentation of practical data
work rather than a traditional resume page. It brings together project
results, analytical insights, machine-learning work, education,
certifications, technical skills, and contact information in a single
responsive website.

The current portfolio highlights two featured projects:

EV Buyer Prediction --- a Random Forest classification model for
estimating the probability of customers purchasing an electric
vehicle.

Superstore Sales Analysis --- a retail analysis exploring sales,
profit, discounting, quantity, categories, segments, and regional
performance.

The site is structured so additional projects can be added as the
portfolio grows.

Run Locally

Because this is a static website, it can be run without installing
dependencies.

Option 1 --- Open directly

Open index.html in a web browser.

Option 2 --- Use VS Code

Open the project folder in VS Code and launch index.html with a local
development extension such as Live Server.

Deployment

The project is suitable for static hosting platforms such as GitHub
Pages and Vercel.

The repository can be connected to a deployment platform so that future
commits automatically update the live portfolio.

Updating the Portfolio

The portfolio is intended to evolve as new projects are completed.

To add a new project:

Add the project's assets to the appropriate folder inside assets/.

Add the project content to index.html.

Update the styling in style.css if a new component is required.

Test the website on desktop and mobile.

Commit the changes with Git.

Push the changes to GitHub.

Let the connected hosting platform deploy the update.

The existing visual system should be preserved when adding future
projects so the portfolio remains consistent.
