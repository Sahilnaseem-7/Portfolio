# Sahil Naseem — Portfolio

A monochrome, editorial portfolio built from plain HTML, CSS and JavaScript.

## Run locally

No npm or build system is required.

Open `index.html` directly in a browser, or use VS Code's Live Server extension.

## Files

- `index.html` — page structure and content
- `style.css` — design system, responsive layout and animations
- `script.js` — navigation, scroll progress, reveal timing, cursor and magnetic interactions
- `assets/Resume.pdf` — resume used by the download button

## Design direction

The visual direction is inspired by the editorial/corporate feel of the Deloitte careers site, without copying Deloitte branding or layout.

## Deployment

This can be deployed directly to GitHub Pages, Netlify or Vercel as a static site.
